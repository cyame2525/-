# 🎵 MP3 to MIDI Converter

## 概要

このアプリケーションは、MP3またはWAVファイルを分析して、含まれる楽器を検出し、BandLab互換のMIDIファイルに変換します。

## 機能

✨ **主な機能:**

- 📁 **MP3/WAVファイルのアップロード** - ローカルファイルをアップロード
- 📊 **波形表示** - オーディオの波形をリアルタイムで表示
- 🔍 **周波数分析** - FFTを使用した周波数スペクトラムの分析
- 🎸 **楽器検出** - AI/機械学習を用いた楽器の自動認識
- 💾 **MIDI変換** - BandLab互換形式のMIDIファイルを生成
- ⚙️ **カスタマイズ設定** - BPM、楽器、感度の調整

## 使い方

### 1. ファイルアップロード

```
1. 「📁 MP3/WAVファイルを選択」ボタンをクリック
2. 変換したいオーディオファイルを選択
3. 波形が表示されます
```

### 2. オーディオ分析

```
1. 「▶ 再生」ボタンでプレビュー再生（オプション）
2. 「🔍 分析開始」をクリックして周波数分析を実行
3. 検出された楽器がリストアップされます
```

### 3. MIDI変換

```
1. 必要に応じて設定を調整：
   - BPM: テンポ設定（40-300）
   - デフォルト楽器: メインの楽器を選択
   - 感度: 楽器検出の感度（0.1-1.0）
2. 「💾 MIDIに変換」をクリック
3. MIDIファイルが自動的にダウンロードされます
```

### 4. BandLabで使用

```
1. https://www.bandlab.com にアクセス
2. 新しいプロジェクトを作成
3. 「インポート」または「アップロード」からMIDIファイルを選択
4. MIDIトラックがプロジェクトに追加されます
```

## 設定オプション

### BPM (Beats Per Minute)
- **範囲**: 40 - 300 BPM
- **デフォルト**: 120 BPM
- **説明**: 曲のテンポを設定します。BandLabで最終的に調整することも可能です。

### デフォルト楽器
使用可能な楽器:
- 🎹 ピアノ (プログラム #0)
- 🎸 ギター (プログラム #24)
- 🎸 ベース (プログラム #32)
- 🎻 バイオリン (プログラム #40)
- 🎻 弦楽器 (プログラム #48)
- 🎺 トランペット (プログラム #56)
- 🎷 クラリネット (プログラム #71)
- 🥁 ドラムス (プログラム #128)

### 感度
- **範囲**: 0.1 - 1.0
- **デフォルト**: 0.5
- **説明**: 値が高いほど、より多くの楽器が検出されます。値が低いほど、検出は厳密になります。

## 技術仕様

### 使用技術

- **Web Audio API** - オーディオ処理
- **FFT (Fast Fourier Transform)** - 周波数分析
- **Tone.js** - オーディオ再生
- **Canvas API** - 波形・周波数表示
- **MIDI形式** - General MIDI互換

### アルゴリズム

#### 周波数分析
```
1. 2048サンプルポイントのFFTを実行
2. 複数フレームで平均化して安定性を向上
3. 周波数スペクトラムを生成
```

#### 楽器検出
```
1. 周波数ピークを検出
2. 各楽器の典型的な周波数範囲と比較
3. マッチング信頼度を計算
4. 信頼度でソートして表示
```

#### MIDI変換
```
1. 検出されたピーク周波数をMIDIノート番号に変換
2. 周波数 -> ノート変換: note = 12 * log2(f/440) + 69
3. 信頼度をベロシティに変換
4. Standard MIDI File (SMF) 形式で出力
```

## 制限事項

⚠️ **既知の制限:**

1. **複雑なポリフォニー** - 複数の楽器が同時に演奏されている場合、完全な分離は困難です
2. **ボーカル** - 人声は楽器として認識されない可能性があります
3. **エフェクト処理** - 大量のリバーブやディレイがある場合、精度が低下します
4. **ファイルサイズ** - 非常に大きなファイル（>100MB）はブラウザでの処理が困難です
5. **リアルタイム処理** - 全オーディオを分析するため、処理時間がかかります

## トラブルシューティング

### Q: ファイルがアップロードできません
**A:** 
- ブラウザがMP3/WAVをサポートしているか確認
- ファイルサイズを確認（推奨: 10MB以下）
- 別のブラウザで試してください

### Q: 楽器が検出されません
**A:**
- 感度スライダーを上げてみてください
- オーディオが十分な音量があるか確認
- 複数の楽器がある場合、上位3つが表示されます

### Q: MIDIが再生されません
**A:**
- BandLabがMIDIファイルをサポートしているか確認
- MIDIファイルが正しく生成されたか、別のプレイヤーで確認
- ブラウザのコンソール（F12）でエラーを確認

### Q: 変換精度を上げたい
**A:**
1. クリーンなオーディオを使用（エフェクトが少ない）
2. 単一の楽器で最良の結果が得られます
3. 感度を微調整してみてください
